    首次使用：阿里云需要配置什么？
    1. 在同一产品下创建设备 web_viewer。
    2. 在产品的“Topic 类列表 → 自定义 Topic”定义 /产品Key/${deviceName}/user/get，权限选择“订阅”。
    3. 在“消息转发 → 云产品流转”中，选择传感器 temperature_humidity 的“物模型属性上报”作为数据源。
    4. 将完整消息转发到下方目标 Topic，发布并启动规则。
    新版解析器示例（把 1000 换成你创建的“数据目的 ID”）：
    旧版 SQL 规则选择 SELECT *，源 Topic 从控制台选择“物模型属性上报”，动作选“发布到另一个 Topic”。不要给规则源 Topic 随意添加 /sys。
